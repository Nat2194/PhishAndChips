### How to install PhishAndChips

1. Clone the repository
   ```
   $ git clone https://github.com/trisl01/L3-S6-PRJ-Solution-Factory
   ```
2. Run these commands in the root of the project :
   ```
   $ cd api
   $ npm i
   $ npm run i:python
   $ cd website
   $ npm i
   ```
3. Go to [this guide](https://github.com/trisl01/L3-S6-PRJ-Solution-Factory/tree/master/docker) and follow all the instructions to set up the Docker container.
4. Open a terminal and run these commands :
   ```
   $ cd api
   $ npm run start
   ```
5. Open a new terminal and run these commands :
   ```
   $ cd website
   $ npm run serve
   ```
   6. Go to `http://localhost:8080` in your web navigator.
      You are now ready to start ! Send your first email to the address you set in the configuration and click on "Obtenir les emails" in the app. Then, click on the mail you want to analyse and wait for the analysis to be completed.
